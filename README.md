Tutorial

como criar um repositório

°crie uma pasta em documentos

°abra essa pasta no VsCod

°abra o terminal do vscod

°selecione gitbash no terminal

°digite "Git Init" (aparecera uma mensagem indicando que um repositorio git foi criado)

°digite "git status" (você vera quais arquivos ainda não estão sendo rastreados)

°digite "git add ."

°entre no github

°entre na sua conta ou se não tiver crie uma

°crie um repositorio clicando em "New"

°dê um nome para esse repositorio

°depois de criar copia o link do https

°entre no vscod de novo

°digite "git remote add origin "https://github.com/NOME DO USUARIO/E REPOSITORIO.git"

°digite "git branch -m main"

°logo em seguida digite "git push -m origin main"

°volte para o github

°adicionar sua dupla no gitbuh

°depois de adicionado conecte-se a sua dupla no github

°E aceite a solicitação
